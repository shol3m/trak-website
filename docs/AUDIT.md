# Аудит UX/функциональности (2026-08-03)

_Последнее обновление: 2026-08-04_

Ручной аудит заказчика по живому Vercel-превью (`trak-website-two.vercel.app`): главная, каталог, карточка товара, сервис, «О нас», контакты, формы, тёмная тема, адаптив. Общая оценка — «примерно 7/10 визуально», но есть критичные функциональные и репутационные проблемы до полноценного запуска.

---

## Уже исправлено (в той же сессии, 2026-08-03)

- **Баг поиска (P0, самое критичное в аудите)** — поиск по точному артикулу падал с тайм-аутом и показывал ложное «ничего не найдено». Причина двойная: не было индекса для поиска по подстроке на 280k строк, и даже после индекса Row Level Security в Postgres не давала планировщику им пользоваться для `ILIKE`. Исправлено через `scripts/add-search-indexes.mjs` (GIN trgm-индексы) + `scripts/add-search-function.mjs` (функция `search_products` в обход RLS), `lib/db-catalog.ts` переведён на неё. Подтверждено на живом сайте: было 3-4 секунды и обрыв, стало 0.4-1 секунда. Подробности — `CLAUDE.md`, раздел «ИЗВЕСТНЫЕ ФИКСЫ ВЕРСИЙ».
- Каталог теперь показывает «Не удалось загрузить каталог» вместо тихой подмены на «ничего не найдено», если запрос к базе падает (`app/catalog/page.tsx`, `app/catalog/[...path]/page.tsx`, `CatalogView.tsx`).
- Переработан текст в `PartFinderCTA`, `ServiceSection`, `about/page.tsx`, `Footer` — меньше канцелярита, без непроверяемых обещаний вроде «перезвоним за 15 минут».
- «30+ лет» → «С 1992 года» — везде на сайте.
- Единый тёмный акцент (синий `#1A3A6B`) вместо разных оттенков синего/чёрного в Header/Footer/`PartFinderCTA`/stats на «О нас». TopBar убран, Header теперь сплошной синий.

## Уже исправлено (сессия 2026-08-04)

- **Сортировка каталога по умолчанию** — «в наличии → с ценой → под заказ» (`stock desc, priceRetail desc`) вместо `id asc`, для обычного листинга и для поиска (`search_products`). Понадобился новый индекс `Product_isActive_stock_priceRetail_idx` (`scripts/add-stock-sort-index.mjs`) — без него дефолтная сортировка по 280k строк тайм-аутила.
- **Фильтры каталога** — «Только в наличии», цена от/до, марка/бренд (`inStock`/`priceMin`/`priceMax`/`brand` в `getProducts()` и `search_products`). Заодно нашли и починили баг: `[...path]/page.tsx` вообще не читал `brand` из URL.
- **Выбор марки/бренда — полноценная разметка вместо 10 вручную выбранных.** Прогнан аудит `Product.brandName` (4646 уникальных значений, топ-461 с 100+ товарами) и вручную классифицирован на Марка/Бренд/Исключить/Серая зона → `docs/brand-classification.tsv`. `lib/categories.ts`: `ALL_VEHICLE_MAKES` (54) + `ALL_PART_BRANDS` (147), `VEHICLE_MAKE_BRANDS` выводится из них. Главная (`StatsBrandsRow`) осталась на компактном топ-4/топ-8. `scripts/audit-brand-classification.mjs` — сверяет живую БД со списком после будущих синков из 1С, печатает только новое.
- **`BrandSelect`** (`components/ui/BrandSelect.tsx`) — нативный `<select>` на 200+ опций заменён на выпадающую панель с полем поиска (живая фильтрация по марке/бренду), сгруппированную «Марки техники»/«Бренды запчастей».
- **Карточка товара** — бренд был мелкой красной плашкой поверх фото/мелким текстом рядом с заголовком, стал крупным кликабельным кикером (`/catalog?brand=...`) над `<h1>`; добавлен блок «Гарантия» (нейтральный текст, без придуманных сроков); колонка под фото сужена (`380px` фикс вместо половины экрана).
- **«Под заказ»** — везде (сетка/список каталога, карточка товара) был на невзрачном сером фоне, неразличим на глаз — переведён на янтарный (`amber`), как у зелёного «В наличии».
- **Бренд на карточках каталога** — красная плашка поверх фото убрана (`ProductCard.tsx`), бренд теперь текстом рядом с артикулом.
- **Иконки** — гаечный ключ, повторявшийся везде как единственная «сервисная» иконка, заменён на смысловые: `lib/service-icons.tsx` — по группе услуги (масло/диагностика/ходовая/двигатель/электрика) в `ServiceSection`/`ServiceCard`; «Собственный сервис» на «О нас» — геометка; «Автосервис» в контактах — иконка авто; черновые hero-баннеры — галочка.
- **Копирайтинг сервиса** — убран список «ГАЗ, ВАЗ, УАЗ, КАМАЗ» из текста сервиса (ошибочно включал КАМАЗ, которого нет в зоне сервиса) → «отечественные авто и иномарки» (`ServiceSection`, `app/service/page.tsx`, `app/about/page.tsx`).
- **«Доставка» убрана везде** — по решению заказчика, условия доставки не готовы объявлять. Убрано из `HeroSlider` (живой слайд), SEO-описания `/catalog`, и из черновиков (`HeroSection`, `TopBar`, `AdvantagesSection`), которые не рендерятся, но чистились по той же логике. Поле «Адрес доставки» в `CartDrawer` оставлено — это функциональное поле формы, не маркетинговое обещание.
- Мелкий фикс инфраструктуры: `.env.local` — строка `DIRECT_URL` была повреждена лишним символом после кавычки, из-за чего `sslmode=disable` не распознавался и локальные скрипты к БД падали по TLS.

## Осталось сделать — по приоритету из аудита

### P0 — блокирует запуск
- **`mockServices`/`mockReviews` в `lib/mock-data.ts` показываются посетителям как настоящие цены и настоящие отзывы.** Нужно подтвердить каждую цену у руководителя сервиса, и либо заменить на реальный прайс, либо явно подписать блок «Ориентировочные цены». Отзывы — только реальные, с указанием источника. Ненастоящий отзыв разрушает доверие ко всей остальной информации на сайте.
- **Нет ссылки на политику обработки персональных данных и текста согласия** рядом с формами (`BookingModal`, `PartRequestModal`, оформление заказа).

### P1
- ~~Каталог по умолчанию показывает сначала товары «под заказ»~~ ✓ (2026-08-04) — сортировка «в наличии → с ценой → под заказ» + фильтры (в наличии / марка / бренд / цена). Категория уже была покрыта деревом URL, отдельного контрола не делали.
- ~~Карточка товара почти пустая~~ ✓ (2026-08-04) частично — добавлена гарантия, редизайн бренда. **Применяемость (совместимость по авто) и условия доставки — не добавлены**: применяемость нельзя показать честно (`ProductCompatibility` в БД пустая, нет данных по совместимости), доставку заказчик попросил убрать вообще, пока условия не готовы объявить.
- На главной `HeroSlider` — 3 слайда, у каждого свой `<h1>` → в DOM одновременно 3 `H1`, это проблема для SEO/семантики разметки. В аудите предложена альтернатива: один статичный первый экран («Запчасти для ГАЗ, УАЗ, ВАЗ и КАМАЗ в Уфе» / «Подберём по VIN, привезём под заказ и установим в собственном автосервисе», кнопки «Подобрать запчасть» + «Записаться в сервис») — это предложение, ещё не согласовано и не сделано.
- Гарантию на работы («гарантия на все виды работ») в идеале заменить на точный срок в месяцах — но только когда появится подтверждённая заказчиком цифра.
- **Новое из этой сессии**: 245 значений `Product.brandName` («серая зона» — заводы-агрегатчики типа ЗМЗ/ЯМЗ/БелЗАН, региональные дистрибьюторы) остались неразмеченными в `docs/brand-classification.tsv`, заказчик доразметит позже. Также не реализован множественный выбор марки/бренда в фильтре (пока один за раз) — согласован план, не сделано.

### P2
- SEO: на `/service` заголовок размечен как `H2`, а не `H1`; «О нас» и «Контакты» используют общий title сайта; `sitemap.ts` — всего 5 статичных URL, без категорий и товаров; нет `robots.ts`; нет OG-изображения; у карточек товара слабое meta-описание при пустом `description`.
- Доступность модалок: `BookingModal`/`PartRequestModal` — добавить `role="dialog"`, `aria-modal`, связать `label` с полями через `id`/`htmlFor`, заблокировать скролл страницы под открытым окном, `max-height: 90dvh` + внутренний скролл для мобильной клавиатуры.
- Серверный rate-limit на `/api/booking`/`/api/order` — сейчас 30-секундное ограничение только на клиенте, обходится прямым запросом к API.
- Стрелки карусели отзывов прижаты к краю экрана — сдвинуть внутрь контейнера.
- Проверить, не перекрывает ли плавающая кнопка WhatsApp кнопки CTA/футер/модалки.

### Мелкая визуальная полировка (не срочно, сделать одним проходом)
- Уменьшить `py-20` до `py-14`/`py-16` на нескольких секциях главной — страница выглядит растянутой.
- В каталоге — большие квадратные заглушки вместо фото у большинства товаров; рассмотреть список как вид по умолчанию, пока нет реальных фото.
- Логотип в хедере визуально мелковат рядом со строкой поиска и кнопкой CTA.
- ~~Тёмная тема — контраст бейджа «Под заказ»~~ ✓ (2026-08-04) — был на сером, неразличим, переведён на янтарный. Остального вторичного текста правка не касалась.
- Панель поиска/сортировки в каталоге не переносится на мобиле — нужен `flex-wrap`.
- Строки услуг на мобиле — перестроить в две строки (название сверху, цена+кнопка снизу).

## Про цифры на сайте

Не добавлять цифры «для красоты». Если добавлять четвёртый показатель к «С 1992 года / 50 000+ / Пн–Вс» (гарантия в месяцах, среднее время ответа, рейтинг/число отзывов) — брать только подтверждённое значение (из базы, от заказчика, с реальной площадки отзывов), не выдумывать.
