# Дизайн-система ТРАК

## Overview

**Creative North Star: "Гараж с чистым учётом"**

ТРАК — не бутиковый маркетплейс: это витрина оптового склада на 280 тысяч позиций, которой пользуются и частник, и снабженец автопарка. Дизайн держит утилитарную честность прайс-листа (моно-шрифт на артикулах, плоские карточки, жёсткие прямые углы) и накладывает на неё один-единственный акцентный жест — красный, который появляется только там, где нужно действие или внимание. Тёмно-синий (#1A3A6B) — это цвет вывески: хедер, футер, тёмные баннеры всегда в нём, независимо от переключателя светлой/тёмной темы сайта, как будто это физическая деталь помещения, а не UI-состояние.

Отвергнуто явно: скруглённые карточки/кнопки (пробовали — заказчик назвал «иишным»), кикер-лейблы над заголовками (тестировали дважды, оба раза убрали по фидбеку заказчика), декоративные emoji (только SVG).

**Key Characteristics:**
- Плоские карточки в состоянии покоя, красное свечение только на hover
- Прямые углы везде, кроме маленьких круглых элементов (бейджи-счётчики, FAB, аватарки в сторис)
- Моно-шрифт зарезервирован строго за артикулами/числами — не для обычного текста
- Тёмно-синий хедер/футер не зависит от темы — фирменный цвет, а не UI-токен

## Colors

Палитра сознательно узкая: один акцент на действие (красный), один фирменный тёмный (синий), один редкий третий (золото — только для одного визуального контекста, отделы на `/contacts`).

### Primary
- **Тревожный красный** (`#C8102E`): единственный цвет для CTA — кнопки, hover-обводка карточек, цена услуги, активные состояния. Hover-затемнение — `#9B0B22`.

### Secondary
- **Форменный синий** (`#1A3A6B`): Header, Footer, тёмные баннеры (PartFinderCTA, слайд 2 Hero), рамка модалок. Не меняется между темами — это идентичность вывески, не тема интерфейса.
- **Синий светлее** (`#2563EB`): редкий вторичный акцент, используется точечно (было в старой версии stats-блока, сейчас почти не встречается — не расширять использование без повода).

### Tertiary
- **Тёплое золото** (`#C4922A`): маркер одного конкретного отдела на `/contacts` (Опт) и рейтинг-звёзды отзывов. Не путать с `brand.gold` (`#D4A017`) в `tailwind.config.ts` — тот токен объявлен, но нигде не используется; реальный золотой везде — `#C4922A` из `globals.css`.

### Neutral
- **Bg Page** (`#F5F5F5` / `#0D0D0D` тёмная): фон страницы целиком.
- **Bg Card** (`#FFFFFF` / `#111111`): карточки, модалки, header/footer-текст на обратном.
- **Bg Muted** (`#EFEFEF` / `#1E1E1E`): чуть темнее карточки — плейсхолдеры изображений, чередование секций.
- **UI Border** (`#E2E2E2` / `#2A2A2A`): единственная граница везде — карточки, инпуты, разделители.
- **Text Base / Dim / Ghost**: три ступени серого для текста — основной / вторичный / почти невидимый (плейсхолдеры).

Статус (не брендовые, семантические): **зелёный** — «В наличии», **янтарный** — «Под заказ» (сознательно не серый — заказчик отметил как неразличимое).

### Named Rules
**The Header-Is-Furniture Rule.** Header/Footer/тёмные баннеры остаются синими `#1A3A6B` в любой теме сайта — это фирменный цвет вывески магазина, а не элемент UI-темизации, и семантические токены (`bg-card`, `bg-page`) на них не распространяются.

## Typography

**Display Font:** Oswald (locale: latin/latin-ext/cyrillic), закреплён на вес 700 — не диапазон
**Body Font:** Inter, вариативный 100–900
**Label/Mono Font:** JetBrains Mono, вариативный 400–800 — **только для артикулов, цен-в-корзине, количества, длительности услуги**, никогда для обычного UI-текста

**Character:** Резкая индустриальная пара — Oswald сжатый и плотный для заголовков/цен (кричит «прайс-лист», не «журнал»), Inter нейтральный и читаемый для описаний. JetBrains Mono вставлен точечно, как перфокарта среди печатного текста — сигнализирует «это код/число, не проза».

Технический нюанс: имена CSS-переменных в коде исторические (`--font-russo`, `--font-ibm-plex`, `--font-ibm-plex-mono`) — шрифты сменились 2026-08-04, названия переменных не переименовывали. Не ориентироваться на имена переменных при определении реального шрифта.

### Hierarchy
- **Display** (Oswald 700, `text-3xl md:text-4xl`, uppercase): заголовки секций (`SectionHeading`), без кикер-лейбла и без акцентной полоски под заголовком — оба элемента убраны намеренно.
- **Title** (Oswald 700, `text-base`–`text-xl`): название услуги/цена товара — цена товара тоже на Oswald, не Inter, трактуется как акцентный элемент.
- **Body** (Inter 400, `text-sm`): описания, копирайт.
- **Label/Mono** (JetBrains Mono, `text-xs`–`text-sm`): артикул, количество в корзине, длительность услуги.

### Named Rules
**The No-Kicker Rule.** Никаких мелких uppercase-подписей над заголовком секций (пробовали дважды, оба раза заказчик назвал «шаблоном ИИ-лендинга») — заголовок стоит один, без обрамления.

## Layout

Контейнер: `max-w-[1280px]`, `px-4 sm:px-6 lg:px-8` (`Container.tsx`, переиспользуется на каждой странице). Fixed header высотой 64px (`pt-16` глобальный отступ в `app/layout.tsx`); страницы каталога/товара добавляют свой `pt-24` поверх.

Сетки карточек: `grid-cols-2` от мобильного (не `grid-cols-1` — тестировали, слишком крупно на телефоне), расширяется до `sm:grid-cols-3 lg:grid-cols-5` на широких секциях (сетка категорий).

## Elevation & Depth

Плоско в покое, тень — исключительно как реакция на hover, не структурный элемент. Ни одна карточка не имеет базовой тени.

### Shadow Vocabulary
- **Card hover glow** (`box-shadow: 0 0 20px rgba(200,16,46,0.15)`): продукт/услуга-карточки при наведении, вместе со сменой границы на красную и `scale(1.02) / translateY(-4px)`.
- **WhatsApp FAB** (`shadow-xl` + `shadow-[#25D366]/30`, ярче на hover): единственный элемент с собственной цветной тенью в состоянии покоя — исключение, обосновано тем, что это плавающая кнопка поверх контента, а не карточка в потоке.

### Named Rules
**The Flat-By-Default Rule.** Тень появляется только как ответ на hover-состояние карточки; в состоянии покоя карточка всегда плоская — граница (`ui-border`) даёт форму, не тень.

## Shapes

**The Square Rule.** `borderRadius: DEFAULT: '0px'` в `tailwind.config.ts` — все кнопки, карточки, инпуты, модалки прямоугольные без исключений. Единственное разрешённое скругление — `rounded-full`, и только для по-настоящему круглых мелких элементов: счётчик-бейдж на иконке корзины, кружки-аватарки в сторис-акциях (`PromoCampaigns`), WhatsApp FAB. Круглая форма сигнализирует «это точка/индикатор», не «это контейнер».

## Components

### Buttons
- **Shape:** прямые углы (`rounded-none`), всегда
- **Primary:** `bg-[#C8102E]` / белый текст, `hover:bg-[#9B0B22]`, паддинг `px-6 py-3` (md)
- **Secondary:** контурная, `border-[#C8102E]` текст красный, заливается красным на hover
- **Ghost:** только текст, `text-dim` → `text-base` на hover, подчёркивание
- **Focus:** видимое `ring-2 ring-[#C8102E]` на всех вариантах — доступность не принесена в жертву минимализму

### Cards (Product / Service)
- **Corner Style:** прямой угол
- **Background:** `bg-card`, граница `ui-border`
- **Hover:** граница краснеет + `shadow-[0_0_20px_rgba(200,16,46,0.15)]` + лёгкий подъём (`scale 1.02, y: -4`)
- **Внутри:** артикул/длительность — моно-шрифт; название — body; цена — display-шрифт, крупнее и жирнее прочего текста карточки

### Modals (Booking / Cart / PartRequest)
- **Overlay:** `bg-black/70 backdrop-blur-sm`
- **Card:** непрозрачный `bg-white dark:bg-[#111111]` (сознательно не полупрозрачный `bg-card` — поверх блюра нужен твёрдый фон), рамка `border-[#1A3A6B]`
- **Форма:** инпуты `bg-bg-page`, ошибка красной рамкой, фокус — синей (`#3B82F6`), не красной — красная зарезервирована за primary-действием

### Story Bubbles (PromoCampaigns)
- Круглый градиентный ободок `from-[#C8102E] to-[#1A3A6B]` вокруг `bg-muted`-круга с SVG-иконкой — единственное место на сайте, где красный и синий соединены в одном градиенте

### Navigation (Header)
- Сплошной `#1A3A6B` независимо от темы, логотип всегда светлый вариант (`/logo-dark.png`), красная CTA-кнопка «Записаться на СТО» — единственный не-нейтральный элемент в хедере, кроме логотипа

## Do's and Don'ts

### Do:
- **Do** использовать моно-шрифт (JetBrains Mono) исключительно для артикулов, чисел и длительностей — не для обычного текста интерфейса.
- **Do** держать hover-tinting карточек в паре «красная граница + красное свечение», не изобретать других цветов свечения.
- **Do** сохранять Header/Footer/тёмные баннеры синими (`#1A3A6B`) независимо от активной темы — это фирменный цвет, не тема.
- **Do** использовать SVG для всех иконок (`stroke="currentColor"`, `viewBox="0 0 24 24"`, `strokeWidth="1.5"`).

### Don't:
- **Don't** добавлять кикер-лейблы (мелкий uppercase-текст) над заголовками секций — убирали дважды по фидбеку заказчика.
- **Don't** скруглять кнопки/карточки/модалки — единственное разрешённое скругление `rounded-full`, для мелких круглых элементов (бейджи, FAB, аватарки сторис).
- **Don't** использовать emoji где-либо в UI — только SVG-иконки.
- **Don't** тянуться к `brand.gold` (`#D4A017`) из `tailwind.config.ts` — токен объявлен, но не используется; реальный золотой — `#C4922A`.
- **Don't** красить статус «Под заказ» в серый — заказчик отметил как неразличимый, обязателен янтарный.
